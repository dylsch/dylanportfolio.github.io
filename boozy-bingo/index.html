Connect Spotify

Spotify needs your own (free) developer app so this page can make playlists on your account. This is a one-time, two-minute setup:

  1. Go to developer.spotify.com/dashboard and log in.
  2. Click Create app. Use any name, e.g. "Boozy Bingo".
  3. Under Redirect URIs, add exactly:
  4. Tick Web API, save, then copy the Client ID into the box below.

Your login stays in this browser only. Nothing is sent anywhere except Spotify.
